# Hidden Message — текст, спрятанный в звуке

Передатчик проигрывает любой mp3 и на лету вшивает в него неслышимый водяной знак с текстом.
Приёмник слушает микрофоном и восстанавливает текст **только из звука** — без доступа к файлу или серверу.

## Запуск

```bash
.venv/bin/python server.py          # раздаёт web/ по HTTPS в локальной сети
```

- **Передатчик** (тот компьютер): `https://<IP этого Mac>:8443/sender.html` → Browse… → mp3 начинает играть →
  пишем текст в поле. Download MP3 — тот же звук с текстом, работает в любом проигрывателе.
- **Приёмник** (этот компьютер / телефон): `https://<IP>:8443/` → Start listening.
- Браузер предупредит о самоподписанном сертификате → «Дополнительно» → «Перейти».

## Как это устроено

- **Сжатие:** общий словарь английского (`web/vocab.json`, 30 000 слов, коды Хаффмана по частоте) —
  в среднем ~11 бит на слово; редкие слова — по буквам. Пересобрать: `tools/build_vocab.py`.
- **Пакет:** синхрослово 48 бит + свёрточный код K=7 r=1/2 (текст + CRC-16), короткое перемежение
  (16 бит) — биты идут почти по порядку; 11 размеров пакета (32…256 бит текста). Пакет крутится по кругу
  весь трек: «Hi there» — круг ~24 с, «Meet me at the old bridge at midnight.» — ~40 с.
- **Водяной знак:** амплитуды частотных ячеек 200–6000 Гц меняются на ±0.9 дБ по псевдослучайному узору,
  соседние ячейки — с противоположными знаками (в пределах полосы слуха изменения гасятся).
  Чип 64 мс, манчестерский код.
- **Приём:** накопление всех повторов пакета для каждого размера, поиск синхрослова, Витерби, CRC.
  Чем дольше слушает — тем надёжнее; старое забывается за ~60 с (смена текста).
- **Слово за словом:** при хорошем сигнале приёмник раскодирует начало пакета, не дослушав круг, —
  слова появляются по мере прихода (~раз в 2 с), недослушанное слово «мельтешит». Догадка показывается,
  только если синхрослово сильное и надёжные слова растут, продолжая прежние (у шума они скачут);
  когда сходится CRC, фраза фиксируется. При слабом сигнале — только итоговая фраза после накопления.
- **Смена текста:** передатчик через ~0.7 с после последней клавиши начинает круг заново с синхрослова.
  Приёмник после подтверждения сверяет звук с узором фразы; когда узор перестаёт совпадать
  (~8–9 с), он выбрасывает старое и пересобирает накопители из последних секунд звука — новая фраза
  идёт по словам примерно через 20 с после окончания набора и подтверждается ~через 27 с.

## Ожидания (проверено через измеренный отклик соседнего MacBook и шум комнаты)

| звук | текст | принят через |
|---|---|---|
| речь + музыка | «Hi there» | ~15 с |
| речь + музыка | «Meet me at the old bridge at midnight.» | первое слово ~15 с, по слову каждые ~2 с, целиком ~34 с, подтверждена ~39 с |
| басовая музыка | «Hi there» | ~32 с |
| басовая музыка | «Meet me at the old bridge at midnight.» | ~56 с (слишком слабо для «слово за словом») |

Короткие сообщения и звук с «серединой» спектра (речь, вокал) принимаются быстрее.
SRT: каждая реплика крутится только в своём интервале — реалистично лишь для длинных реплик (40 с+).

## Утилиты

- `node tools/encode.js in.mp3 out.mp3 "text"` — то же, что Download в передатчике.
- `node web/decoder.js file --text` — декодировать файл/запись.
- `https://…/?autostart&file=x.wav` — приёмник берёт звук из файла в `web/` вместо микрофона.
- `encode.py` — старый ультразвуковой канал (приёмник его тоже понимает, но динамики ноутбуков/телефонов
  ультразвук почти не воспроизводят).
